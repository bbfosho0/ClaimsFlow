# ClaimsFlow World-Class Visual Redesign

## Goal

Create a premium dark operational system in Figma for ClaimsFlow, led by an Evidence Ledger, Operator Command Grid, and Explainable Copilot Review.

## Canonical frames

1. **Operations Overview** is a telemetry command center: grouped navigation, connected KPI instruments, operational pulse, SLA constellation, exception watchlist, workload, audit feed, and live footer.
2. **Claims Queue** is a triage console: command search, saved views, active filters, dense prioritised table, claim inspector, and AI summary.
3. **Claim Workspace** is an evidence ledger: persistent identity, local tabs, source rail, extracted-fact/completeness center pane, and violet human-review decision rail.

## System rules

- Canvas and panels use deep navy; cyan and teal convey operational flow; violet is reserved for intelligence/recommendations; amber/coral express risk.
- Status always combines copy and color. Claim IDs, timers, and financial data use a monospace treatment.
- Reusable components retain the established app shell, badges, KPI instruments, panels, filters, and claim-table grammar.
- Animation annotations: KPI crossfade, 180ms inspector slide/fade, 140ms chips, subtle risk border trace; reduced motion removes texture and interpolation.

## Figma delivery

The editable Figma target is https://www.figma.com/design/M7GOuna2hq7jWCGTZhiP5b. Foundations, component library, and all three canonical frames are the approval anchor for future pages.

The local `ClaimsFlow / Tokens` collection provides named editable color variables for canvas, surfaces, borders, text, operational signals, intelligence, risk, and critical states.
